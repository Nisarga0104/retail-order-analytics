# Retail Order Analytics

## Project Overview

Retail Order Analytics is an end-to-end data analytics portfolio project focused on analysing retail operations, sales performance, customer behaviour, inventory, supplier performance, shipments, payments, and product returns.

The project uses a synthetic retail dataset to demonstrate practical SQL analysis, data modelling, data quality validation, and business intelligence reporting.

## Business Objectives

- Analyse overall sales and revenue performance.
- Identify top-performing products, categories, and customers.
- Understand customer purchasing behaviour.
- Monitor inventory levels and identify low-stock products.
- Evaluate order cancellations and payment activity.
- Analyse shipment and delivery performance.
- Examine product returns and refund patterns.
- Perform data quality checks and payment reconciliation.

## Dataset Note

This project uses synthetic data created for educational and portfolio demonstration purposes. It does not represent actual transactions or a real retail business.

The available sales dataset covers June and July. Therefore, monthly trends should be interpreted within this limited period.
